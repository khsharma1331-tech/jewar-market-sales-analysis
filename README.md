# Jewar Market Sales Analysis - Impact of Noida International Airport

### Overview
A sales data analysis project showing how Noida International Airport construction impacted local market sales in Jewar, Noida and nearby regions. This is a pre-launch study (2024 data) which predicted the boom we see in 2026 after airport became operational.

### Problem Statement
Local shopkeepers in Jewar were unsure which products to stock after the airport announcement. This project answers: Which category sells most? Which region is growing fastest? Is there a monthly growth trend?

### Dataset Information
- File: `sales_data.csv` (50 rows)
- Columns: OrderID, Product, Category, Quantity, Price, Region, Date, Total_Sales
- Period: Jan 2024 - June 2024 (Construction Phase)
- Regions: Jewar, Noida, Delhi, Ahmedabad, Bijnor
- Total Revenue Analyzed: Rs 37,19,508

### Tech Stack
- Python
- Pandas for data analysis
- Matplotlib for visualization

### Files in this Repo
1.  sales_data.csv - Main dataset (50 transactions)
2.  analysis.py - Python code for analysis
3.  category_sales.png - Bar chart: Sales by Category
4.  region_sales.png - Bar chart: Sales by Region
5.  monthly_sales_trend.png - Line chart: Monthly trend

### Key Insights
1.  Electronics dominates with 93% sales (Rs 34.9 Lakh) - Laptop and Mobile are top sellers due to airport staff and engineers buying premium products.
2.  Jewar (Rs 13.4 Lakh) + Noida (Rs 12.8 Lakh) = 70% of total sales. Jewar is emerging as a premium market.
3.  Monthly sales grew from Rs 65k in Jan to Rs 8.5 Lakh in Feb and Rs 7.7 Lakh in May, showing clear growth during construction phase.
4.  Clothing and Grocery are stable but low - future growth expected after 2025-26 airport opening.

### Business Recommendation (2026 Perspective)
Data from 2024 already showed Jewar market growing. Now in 2026, after airport is operational, this trend has multiplied. Shopkeepers should stock more Electronics and focus on premium products for travelers and airport staff.
